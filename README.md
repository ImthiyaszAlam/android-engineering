# Android Engineering

**Building production-ready Android applications with Kotlin, modern Android architecture, and Jetpack libraries.**

This repository brings together my Android development work across application development, interview preparation, hands-on practice, and exploration of modern Android technologies.

## Technologies

- **Languages:** Kotlin, Java
- **UI:** Jetpack Compose, XML, Material Design
- **Architecture:** MVVM, Clean Architecture
- **Jetpack:** Room, WorkManager, Navigation
- **Networking:** Retrofit, REST APIs, WebSockets
- **Asynchronous Programming:** Coroutines, Flow
- **Dependency Injection:** Hilt
- **Tools:** Android Studio, Git, GitHub

## What I Focus On

- Building maintainable Android applications using modern architecture.
- Implementing offline-first functionality and reliable background synchronization.
- Integrating REST APIs and handling asynchronous data flows.
- Improving application performance, stability, and user experience.
- Exploring Android internals, system design, and engineering best practices.
